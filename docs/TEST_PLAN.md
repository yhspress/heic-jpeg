# 브라우저 검증 체크리스트

자동 테스트는 공식 파일 조건 설정을 검증한다. 실제 HEIC 디코딩은 브라우저와 샘플 파일에 의존하므로 배포 전 아래 수동 검증도 수행한다.

| 시나리오 | 기대 결과 |
| --- | --- |
| 정상 iPhone HEIC | JPEG 다운로드 가능, 원본과 동일한 방향·픽셀 수로 표시 |
| 손상된 HEIC | 오류 안내, 다운로드 버튼 미표시 |
| JPEG 업로드 | 이미 JPEG라는 안내, 재변환하지 않음 |
| 7MB 초과 또는 20KB 미만 결과 | 변환 후 파일 용량이 `要確認`으로 표시 |
| 480px 미만/6000px 초과 | 이미지 크기가 `要確認`으로 표시 |
| iOS Safari 최신판 | 사진 선택, 변환, 다운로드, 세로 사진 방향 확인 |
| Chrome 최신판 | 드래그앤드롭, 변환, 다운로드, 오류 안내 확인 |

테스트용 사진에는 실제 개인번호나 식별 가능한 민감한 정보를 포함하지 않는다.
